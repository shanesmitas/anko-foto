---
title: モード早見表
description: 実機で見えたカメラモードと向いている場面。
---

| モード           | 向いている場面     | 最初のコツ           |
| ---------------- | ------------------ | -------------------- |
| 写真             | ふだんの一枚       | 1×で被写体をタップ   |
| ポートレート     | 人やペット         | 背景から距離を取る   |
| ナイトビジョン   | 暗い街や室内       | 両手で止める         |
| パノラマ         | 長い景色           | ゆっくり一定に動く   |
| 最大画素         | 明るく動かない細部 | 端末を安定させる     |
| プロ             | 動きなどを調整     | 一つずつ変える       |
| スキャン         | 紙やノート         | 紙と平行に構える     |
| タイムラプス     | 雲や影の変化       | 安全に固定する       |
| スローモーション | 短い動き           | 明るい場所で撮る     |
| チルトシフト     | ミニチュア風       | 細部の多い景色を選ぶ |

スローモーションのフレーム数など、表示から確認できない値は端末で確かめてください。
