## まず自動を基準に

プロ画面では ISO、シャッター速度（S）、ホワイトバランス（WB）、フォーカス（AF）が見えます。すべてを手動にせず、一つだけ変えると違いが分かります。

| 設定 | 役割               | この端末で確認済み |
| ---- | ------------------ | ------------------ |
| S    | 動きを止める／流す | 自動、1/350        |
| ISO  | 明るさとざらつき   | 自動、100、200     |
| WB   | 色味               | 自動               |
| AF   | ピント             | 自動               |

### 動くものの出発点

S を **1/350**、ISO・WB・AFは**自動**。まだぶれるなら、終点を決めつけずシャッターを速い方向へ動かします。全範囲は未確認です。

## 変えるとどうなる？

- シャッターを速くする：光が減って暗くなる代わりに、動きのぶれが減ります。
- シャッターを遅くする：光が増えて明るくなる代わりに、動きや手ぶれが増えます。
- ISOを高くする：明るくなる代わりに、ざらつきが増えます。
- ISOを低くする：ざらつきは減りますが、光を増やすかシャッターを遅くしないと暗くなります。
- EVは自動露出の明るさを調整します。シャッターとISOを両方手動にした時にも使えるとは限りません。
- この実機の操作列に絞りはありません。絞り値を変える設定として教えません。
