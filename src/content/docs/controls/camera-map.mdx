## 覚える場所

1. **0.5× / 1× / 2×**：写る範囲の選択。2×が独立した望遠レンズかは未確認です。
2. **白い丸**：写真を撮るシャッターボタン。
3. **写真・ポートレート・詳細**：目的に合わせてモードを変える場所。
4. **回転する矢印のアイコン**：前面と背面カメラの切り替え。

**プロ**は「詳細」のタイルではなく、画面下のモード列にあります。

画面表示はカメラアプリの更新で変わることがあります。
