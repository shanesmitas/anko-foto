# Project: Japanese/English Mobile Photography Guide for a Japanese Motorola Smartphone

I want you to research, design, build, test, and ultimately deploy a small mobile-first bilingual photography-learning website for one specific Motorola Android smartphone.

The intended primary reader is a 14-year-old Japanese girl who is interested in experimenting with photography but is a beginner.

This should NOT feel like a technical camera manual.

It should feel like a small, attractive, extremely easy-to-use photography companion that she can open on her phone while she is taking pictures.

The primary output will be a static website deployed to GitHub Pages.

Secondary outputs, after the website is stable, should include:

- a Japanese quick-reference image suitable for saving in the phone's Photos/Gallery
- an English quick-reference image
- a concise bilingual PDF/offline guide if practical
- a source/attribution record

The project should remain lightweight, static, inexpensive/free to host, and easy to maintain.

# 5. Core UX philosophy

This guide is for someone USING the camera, not studying for a photography exam.

The most important design principle:

### Get her to a useful setting in seconds.

Japanese should be the DEFAULT language.

English should be available through a prominent:

`日本語 | EN`

language switch.

When switching languages, keep the user on the equivalent page wherever possible.

Do NOT show Japanese and English simultaneously in long side-by-side blocks on mobile.

Use separate localized versions.

Photography abbreviations should remain recognizable:

- ISO
- WB
- AF
- EV

Japanese text can introduce them as:

- ISO感度 (ISO)
- ホワイトバランス (WB)
- フォーカス (AF)
- 露出補正 (EV)
- シャッタースピード (Shutter Speed)

Japanese must be natural, simple Japanese suitable for approximately a middle-school reader.

Do not write childish Japanese.

Do not write literal machine-translated English.

Tone should be:

- friendly
- clear
- encouraging
- concise
- visual
- practical

Avoid large paragraphs.

# 6. Mobile-first design

Design primarily for approximately 360–430px phone screens.

Requirements:

- single-column layout on mobile
- no horizontal scrolling
- body text at least ~17px where practical
- generous Japanese line height
- minimum ~44px touch targets
- high contrast
- readable in sunlight
- responsive images
- lazy-load noncritical images
- compressed WebP/AVIF where appropriate
- semantic HTML
- accessible controls
- useful alt text
- system light/dark mode or an easy theme control
- no tiny tables

For settings, use large visual chips/cards such as:

[ 1× ]
[ ISO 100 ]
[ 1/250秒 ]
[ WB 6000K ]

The key settings for a recipe should appear immediately without scrolling through an essay.

The design should be modern and attractive but not overly childish.

No unnecessary animations.

No heavy JavaScript if static HTML/CSS can do the job.

# 9. Teach only the controls she can actually use

Do not teach DSLR controls as though the phone provides them.

For example:

If the phone has a fixed aperture and no manual aperture setting, explain briefly:

### Why can't I change aperture?
Because this phone's camera lens uses a fixed aperture. You control brightness mainly through shutter speed, ISO, exposure compensation, and the phone's automatic processing.

Do NOT present the classic ISO/shutter/aperture “exposure triangle” as three manually adjustable controls if aperture is fixed.

A better beginner framework for THIS phone might be:

### Shutter Speed
Controls movement + affects brightness.

### ISO
Controls sensitivity/brightness + noise.

### Exposure Compensation
Tells Auto exposure to make the result lighter/darker.

### White Balance
Controls warm/cool color.

### Focus
Controls what is sharp.

Build the education around the hardware in her hand.

# 10. Visual learning pages

For each major variable, create a visual comparison.

Show the SAME type of moving subject at several speeds.

Example conceptual progression:

1/500 → frozen
1/125 → mostly frozen
1/30 → visible movement
slowest supported value → strong motion blur

## ISO

Same scene:

ISO 100 → clean
ISO 400 → brighter/some noise
ISO 800 → more noise
ISO 1600+ → significant noise

Use only values the phone actually offers.

## White balance

Same scene at, for example:

4000K → cooler
5000K
6000K
7000K → warmer

Only if those settings/ranges are actually available.

## Exposure compensation

-1 EV
0
+1 EV

Explain simply:

darker ← normal → brighter

## Focus

near object → middle subject → distant scenery

Whenever using simulated comparison imagery, label it clearly as an illustrative example rather than pretending it was captured at that exact physical setting.

# 11. Photography recipes

This is the heart of the site.

Each recipe must have the same predictable layout.

Example:

# 夕焼けの橋 — 車をくっきり撮る

[large example image]

## まずこれを試そう

Mode: Pro
Lens: 1x
Shutter: 1/250
ISO: 400
WB: 6000K
Focus: AF

Then:

### 暗すぎる？
ISO 400 → 800

### 車がブレる？
1/250 → 1/500

### 空が白っぽい？
Reduce exposure slightly if compatible with the selected manual controls.

### 何が変わる？
A faster shutter freezes movement.

The equivalent English page:

# Sunset Bridge — Freeze the Cars

[image]

## Try this first

...

Recipes should provide STARTING POINTS, not pretend a setting guarantees correct exposure in every light condition.

Use language such as:

“Start here”
“Try this”
“If it looks too dark...”

rather than:

“This is the correct setting.”

# 13. “My picture looks wrong” troubleshooter

This should be one of the most useful pages.

Create large problem cards.

## 写真が暗い
Too dark

Try:
- slower shutter if appropriate
- higher ISO
- return a control to Auto
- use Night Vision where appropriate

## 写真が明るすぎる
Too bright

Try:
- faster shutter
- lower ISO
- lower exposure compensation where applicable

## 動いているものがブレる
Moving subject is blurry

Try:
- faster shutter
- enough ISO to support that shutter speed

## 全部ブレている
Everything is blurry

Try:
- brace the phone
- use timer
- faster shutter
- avoid moving the phone

## ザラザラしている
Too grainy/noisy

Try:
- lower ISO
- more available light
- Night Vision where suitable

## 夕焼けが白っぽい
Sunset looks washed out

Try:
- reduce exposure
- meter/focus on the sky if suitable

## 色が青すぎる・黄色すぎる
Too blue/yellow

Try:
- WB adjustment
- Auto WB

## ピントが合わない
Out of focus

Try:
- tap the subject
- AF
- manual focus only when useful

The instructions must account for interactions between manual settings.

For example, if ISO and shutter are both fully manual, EV may not behave like it does in Auto exposure.

Research the actual behavior.

# 28. Product success criterion

1. tap “Moving Cars” or “Sunset”
2. see exactly which Motorola camera mode to open
3. see which lens to choose
4. see a starting shutter speed
5. see a starting ISO

7. see an example of the expected effect
8. know what to change if her photo is too dark or blurry

If the website achieves that reliably, the product is succeeding.
